# Haven Suites – Hotel Booking Website

## Project Description
Haven Suites is a responsive hotel booking website built with React. It allows users to explore available rooms, view room details and prices, make reservations, and contact the hotel. It provides a user-friendly interface with easy navigation and interactive forms.

## Features
- Home page with hotel introduction.
- About page with information about the hotel.
- Rooms page displaying available rooms and prices.
- Booking form for making reservations.
- Contact page with an interactive contact form.
- Responsive design for mobile and desktop devices.
- React Router for navigation.
- Reusable React components.
- Booking and contact form submissions stored in the browser's local storage.

## Technologies Used
- React.js
- JavaScript
- HTML5
- CSS3
- React Router DOM
- Vite

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_LINK
   ```

2. Navigate into the project folder:

   ```bash
   cd haven-suites
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal to view the website.

## Important Note
This project is a frontend demonstration. Booking and contact form submissions are stored in the browser's local storage. It does not currently use a backend database or process real payments.
